# Nook

[English](README.md)

Лёгкий помощник для креаторов на OnlyFans и Fansly в боковой панели Chrome (Side Panel API), рядом с открытым чатом: заметки по фану, его траты и списки, проверка набираемого текста, шаблоны, AI-правка и чат с AI про фана. Альтернатива громоздким CRM.

## Принципы

- **Только то, что страница даёт сама.** Никаких закрытых API, перехвата запросов и токенов.
- **Ничего не встраиваем в страницу.** Контент-скрипт читает DOM. Исключения две: он не даёт отправить сообщение с запрещённым словом (см. ниже) и по явной кнопке в панели вставляет текст в поле ввода чата.
- **Фан определяется по URL чата:** `onlyfans.com/my/chats/chat/<id>` и `fansly.com/messages/<id>`. Своего списка фанов в панели нет: только фан открытого чата и чаты, которые сейчас видны в списке OnlyFans.
- **Чаты на экране (OnlyFans).** Контент-скрипт читает видимые строки списка чатов (`.b-chats__item[id]`, id = id фана, тот же, что в URL чата; порядок по `data-index`, потому что список виртуальный). Панель сопоставляет их с сохранёнными тратами: на странице `/my/chats` это отдельный экран в том же порядке, что на сайте (фильтры All / Unread / $100+), а в открытом чате вкладка «On screen» рядом с карточкой фана (порядок как на сайте или по тратам). $1,000+ выделяются, меньше $100 приглушены (`SPENDER`, `WHALE` в `src/lib/spending.ts`). Клик по строке открывает чат по ссылке (страница перезагружается). «Check spending» по одному открывает профили непроверенных фанов в фоновых вкладках: следующий только после того, как закрылся предыдущий, и через 5 секунд (`BULK_PAUSE`), примерно как если прокликивать их руками. Если профиль отвечает «this page is not available» (аккаунт удалён или забанен), вкладка сразу закрывается, а фан помечается как gone: его не открывают снова 3 часа, прежние траты остаются. Открыл чат из «On screen», и панель переключается на карточку этого фана (вкладка AI при смене чата остаётся); если ты в это время открываешь чат, его профиль идёт первым.
- **Заметки по фану** выглядят как блокнот: каждая заметка — строка (может быть многострочной, Shift+Enter), старые сверху, дата справа. Кликнул — правишь на месте, сохраняется по ходу набора. Enter переходит к новой заметке внизу. Пустая заметка удаляется, несколько секунд можно нажать Undo. При импорте бэкапа из двух копий одной заметки остаётся отредактированная последней (`updatedAt`).
- **Данные хранятся только в браузере** (`storage.local`). Для переноса и бэкапа в Settings → Your data есть экспорт/импорт JSON (фаны, шаблоны, слова; ключ AI туда не попадает).
- **Траты фана (OnlyFans).** Когда ты задерживаешься в чате, расширение открывает профиль фана в фоновой вкладке (как если бы ты сам зашёл), читает блок «Fan statistics» и списки, в которых состоит фан (они видны над обложкой профиля), и закрывает вкладку. Не чаще раза в 3 часа на фана (`STATS_MAX_AGE` в `src/lib/statsFetcher.ts`). Если ты открываешь профиль сам, данные обновляются тоже. В Settings → Spending это можно выключить («Look up spending on its own»): тогда профиль открывается только по ссылке «Look up» на карточке фана или по «Check spending».
- **Траты фана (Fansly).** Fansly показывает их только в окне «Supporter» (в чате «⋯» → «Earnings»), а кнопки на странице расширение не нажимает. Поэтому цифры сохраняются, когда ты сам открываешь это окно в чате с фаном. Данные за «Lifetime» не затираются цифрами за более короткий период.
- **Запрещённые слова.** Проверка идёт по трём спискам (что проверяется на каком сайте: `src/lib/wordLists.ts`, совпадения: `src/lib/restricted.ts`):
  - **Встроенный** (`src/lib/baseWords.ts`): публичный список, 911 слов по алфавиту. Держит отправку так же, как свои слова. Сам список не редактируется: нажатие на слово разрешает его (везде или на одном сайте).
  - **Свои слова** (`customWords`) держат отправку на всех сайтах. По умолчанию пусто, в бэкап попадают.
  - **Разрешённые** не помечаются никогда, даже если они есть в списке или их накрывает запись со `*` (например свой @ник под `@*`). Слово можно разрешить везде (`allowedWords`) или только на одном сайте (`allowedOn`): в Settings → Restricted words → Built-in нажми на слово и выбери, где его разрешить.
  Пока в поле ввода есть слово, которое держит отправку, Enter и нажатие на «Send» до сайта не доходят: слушатель на `window` в фазе захвата перехватывает и клавиши (keydown, keypress, keyup), и кнопку мыши целиком (pointerdown, mousedown, pointerup, mouseup, click, касания), на случай если сайт отправляет не по клику. Текст остаётся в поле, кнопки расширение не нажимает, на иконке Nook загорается красный «!». Ищутся только целые слова, но маскировка распознаётся (p.a.y.p.a.l, p@yp4l, кириллица). `*` на краю слова ищет часть слова: `pay*`. Проверка идёт без регулярных выражений: каждое слово пробуется только там, где с его первой буквы начинается слово в тексте, поэтому тысяча с лишним слов проверяется за доли миллисекунды. Перехват можно выключить (Settings → Hold back sending). AI получает свои слова списком, а то, о чём встроенный список, коротким перечнем тем (`AVOID_SUBJECTS`). Селекторы поля ввода и кнопки отправки лежат в таблице `COMPOSERS` в `src/lib/composer.ts`.
  Старые настройки с одним списком `restrictedWords` переносятся в свои слова сами (заглушки первой версии выбрасываются).
- **Вставка в чат.** Кнопки Insert вставляют текст в поле ввода сайта через `document.execCommand('insertText')`, как если бы ты вставил его сам; отправляешь ты. Если выключить Settings → Insert into chat (или поле не найдено), текст копируется, и ты вставляешь его ⌘V.
- **Шаблоны сообщений** открываются кнопкой «Templates» внизу панели. У шаблона нет названия: текст, теги и звёздочка. Есть поиск, фильтр по тегам, избранные наверху, остальные по частоте использования; ↑↓ и Enter выбирают. `{name}` заменяется именем фана. Шаблон с запрещённым словом подсвечивается красным, и вставить его нельзя. Шаблоны хранятся в `settings` и попадают в бэкап.
- **AI (OpenRouter).** Работает на твоём ключе OpenRouter (Settings → API key), модель выбирается в Settings → Model (по умолчанию Grok 4.7). Ключ хранится в `storage.local` под `ai` и не попадает в бэкап. Всё уходит на модель только по кнопке.
  - **Spelling** исправляет опечатки и показывает правки по словам. Сначала проверяет дешёвая модель (`SPELLING_MODEL` в `src/lib/ai.ts`, GPT-6 Luna); если она отказала (фильтр контента) или не ответила, проверяет выбранная модель (если выбрана сама Luna, то Grok 4.7). Уходит только текст сообщения.
  - **Improve** пишет 3 версии по черновику, по твоей инструкции или по обоим. Уходят текст и список запрещённых слов.
  - **Вкладка AI** рядом с фаном: чат с моделью про этого фана. С каждым вопросом уходит то, что разрешено в Settings → What AI sees: сообщения чата, загруженные на странице (до 40 последних; контент-скрипт читает `.b-chat__message` на OnlyFans и `app-group-message` на Fansly), карточка фана (траты, подписка, списки) и последние 10 обменов с AI по этому фану. Ещё уходят текст в поле ввода, «твой стиль» и запрещённые слова. Заметки не уходят. Переписку можно выключить одной кнопкой «Chat» под полем вопроса. Готовые сообщения модель присылает в `<msg>…</msg>`, панель показывает их карточками с Insert и проверкой на запрещённые слова. История хранится в `storage.local` под `ai-chat:<фан>` и в бэкап не попадает.
- **Тема:** System, Light или Dark в Settings.

## Стек

[WXT](https://wxt.dev) + React + TypeScript, тесты на Vitest. Нужна Node 22+.

## Команды

```bash
npm install          # зависимости + генерация типов WXT
npm run dev          # Chrome с расширением и hot reload
npm run build        # сборка в output/chrome-mv3
npm run zip          # zip для релиза
npm run compile      # проверка типов
npm test             # юнит-тесты
npm run preview:panel  # панель в обычной вкладке с фейковым chrome.* API: http://127.0.0.1:5178/
                       # ?ai=fake — выдуманные ответы OpenRouter, ?luna=refuse — дешёвая модель отказывает,
                       # ?theme=light|dark, ?url=<адрес вкладки>
```

Установка вручную: `chrome://extensions` → Developer mode → **Load unpacked** → папка `output/chrome-mv3`. После `npm run build` нажми ↻ на карточке Nook. Скрипт страницы Chrome добавляет только во вкладки, загруженные после установки или обновления, поэтому уже открытые вкладки OnlyFans и Fansly нужно перезагрузить. Панель сама это предложит («Reload the page to turn Nook on»).

## Структура

```
src/
  entrypoints/
    background.ts     открывает панель по клику на иконку, фоновые вкладки за тратами, красный значок
    content.ts        читает со страницы фана, траты, сообщения чата и текст в поле ввода; держит защиту от запрещённых слов
    sidepanel/        UI панели (React)
  lib/
    platforms.ts      распознавание чата по URL
    store.ts          хранилище фанов и настроек (слова, шаблоны), очередь записей, экспорт/импорт
    page.ts           что читать со страниц (селекторы в таблице SITES, список чатов OnlyFans, сообщения чата)
    spending.ts       траты фана числом и пороги выделения
    composer.ts       поле ввода чата и защита отправки (селекторы в таблице COMPOSERS)
    restricted.ts     поиск запрещённых слов и исключений
    wordLists.ts      какие слова проверяются на каком сайте: встроенные, свои, разрешённые везде или на одном сайте
    baseWords.ts      встроенный список слов, по алфавиту
    templates.ts      подстановка {name} в шаблоны
    ai.ts             орфография, улучшение и чат с AI через OpenRouter (ключ пользователя, не в бэкапе)
    aiChat.ts         последние 10 обменов с AI по каждому фану (не в бэкапе)
    diff.ts           что поменял AI, по словам
    statsFetcher.ts   фоновая вкладка с профилем фана для трат на OnlyFans
    messages.ts       сообщения между контент-скриптом и панелью
tests/                Vitest
docs/index.html       лендинг проекта (одна страница без зависимостей, подходит для GitHub Pages)
dev/chrome-mock.js    фейковый chrome.* для preview:panel
scripts/              сервер превью панели
```
